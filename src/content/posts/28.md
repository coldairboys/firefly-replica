## 一、全新官方桌面端安装（最推荐·零门槛） {#一全新官方桌面端安装最推荐零门槛}

官方桌面端针对个人日常使用进行了全方位的平民化优化，内置了完整的沙箱与运行环境，彻底告别了“配置 2 小时，运行 5 分钟”的终端环境困扰。

### 1.1 跨平台安装包下载

前往官方 GitHub Releases 页面（https://github.com/NousResearch/hermes-agent/releases ）下载对应系统的最新安装包：

* **Windows 用户**：
  * 下载 `Hermes-Agent-Setup-x.x.x.exe`（标准安装向导）或 `Hermes-Agent-Portable.zip`（免安装便携绿色版）；
  * 双击 `.exe` 一键安装，直接在桌面上生成启动快捷方式。
* **macOS 用户**：
  * **Apple Silicon 芯片（M1/M2/M3/M4 系列）**：下载 `Hermes-Agent-x.x.x-arm64.dmg`；
  * **Intel 芯片**：下载 `Hermes-Agent-x.x.x-x64.dmg`；
  * 打开 DMG 文件，将 Hermes Agent 图标拖入 `Applications`（应用程序）文件夹即可。
* **Linux 用户**：
  * 下载 `Hermes-Agent-x.x.x.AppImage` 或 `.deb` 安装包；
  * AppImage 赋权并启动：
    ```bash title="Linux 终端"
    chmod +x Hermes-Agent-*.AppImage
    ./Hermes-Agent-*.AppImage
    ```

> [!NOTE]
> macOS 首次打开若提示“无法验证开发者”，请进入系统「设置」→「隐私与安全性」，滑动到最下方点击「仍要打开」即可正常启动。

## 二、桌面端核心功能与实操配置 {#二桌面端核心功能与实操配置}

桌面端不仅提供了流畅的现代化图形界面，更将 Hermes Agent 最强大的多层记忆与工具箱进行了全面可视化：

### 2.1 核心特性一览

1. **可视化四层记忆浏览器（Memory Inspector）**：
   * **工作记忆（Working Memory）**：实时查看 Agent 当前思考的上下文与会话状态；
   * **情景记忆（Episodic Memory）**：按时间轴检索历史对话与过往任务的快照；
   * **语义概念图谱（Semantic Memory）**：直观展示 Agent 从日常对话中自动提炼沉淀的知识概念网络；
   * **程序性记忆库（Procedural Skills）**：Agent 在解决复杂任务过程中自主编写并验证的 Python 技能函数，全部可以在侧边栏点击查阅和单独调用。
2. **极简模型接入面板**：
   * 支持一键填入 API Key，原生支持 Anthropic Claude 3.7 / 3.5 Sonnet、OpenAI GPT-4o、DeepSeek-V3 / R1、OpenRouter 等各大主流模型；
   * 原生兼容本地推理框架（Ollama / vLLM / LM Studio），只需在界面中填入本地地址（如 `http://127.0.0.1:11434`），免去手写环境变量文件的麻烦。
3. **40+ 工具箱与权限审批机制**：
   * 网页检索（Web Search）、代码沙箱执行（Code Interpreter）、本地文件读写、系统监控等工具均提供图形开关；
   * **安全审批模式**：当 Agent 试图写入磁盘重要路径或执行敏感系统命令时，桌面端会自动弹出审批确认框，防范潜在风险。
4. **Artifacts 画布分栏**：
   * Agent 输出的代码、网页原型、Markdown 格式化报告将独立展示在右侧画布栏，支持实时预览、一键复制代码或导出到本地目录。
5. **本地 / 远程网关连接（Gateway Mode）**：
   * 桌面端既可以在本地单机独立运行，也可以作为远程客户端连接跑在云端 Linux 服务器上的 Hermes Agent 网关，实现多端会话无缝同步。

### 2.2 桌面端快速上手三步法

1. **第一步：启动应用并选择模型**：
   打开桌面端，点击左下角 **Settings（设置）** → **Models（模型）**，选择你的主力模型提供商（例如 OpenRouter 或 DeepSeek），填入你的 API Key 并点击 **Test Connection（测试连接）**。
2. **第二步：配置工具与能力**：
   进入 **Tools（工具）** 选项卡，勾选开启 **Web Search（网络搜索）** 与 **Python Sandbox（代码沙箱）**，赋予 Agent 实战解决问题的能力。
3. **第三步：开启自主进化对话**：
   新建会话，像与资深工程师结对一样给它下发任务。例如：
   > "请帮我调研 2026 年最流行的 3 款前沿 RAG 框架，对比它们的技术架构优缺点，并将对比结论总结成 Markdown 表格沉淀到你的技能库中。"

你会看到它自动拆解任务、调用网页搜索、提炼知识并将其持久化保存到记忆面板中。

## 三、桌面端 vs CLI 终端版选型对比 {#三桌面端-vs-cli-终端版选型对比}

| 比较维度 | 官方桌面端 (Desktop App) | CLI 终端交互版 (Terminal CLI) |
|---|---|---|
| **适合人群** | 个人日常使用、普通写作者、知识工作者、非极客 | 开发者、DevOps、服务器管理员、极客玩家 |
| **安装门槛** | ⭐ **零门槛**（双击安装包即可） | ⭐⭐⭐ **中等**（需配置 Python / Git / WSL2） |
| **Windows 支持** | ✅ **原生支持**，无需虚拟化 | ⚠️ 需通过 WSL2 虚拟机或 Docker 运行 |
| **界面与排版** | 现代 GUI、Markdown 渲染、多栏 Artifacts | 纯终端字符界面（Rich / Textual TUI） |
| **记忆与技能查看** | 图形化记忆浏览器、思维导图式概念卡片 | 终端命令或手动查阅 SQLite 数据库 |
| **系统资源占用** | 包含完整 GUI 界面，内存占用约 300~500MB | 轻量极简，内存占用通常 100~200MB |
| **自动化与常驻** | 适合人机交互，随开随用 | 适合服务器无人值守常驻、Systemd 守护、消息机器人 |

> [!TIP]
> 如果你的诉求是：在本地电脑上像使用 ChatGPT / Claude 桌面应用一样，方便快捷地让 Agent 帮你干活、查资料、写代码，**请毫不犹豫选择桌面端**！

## 六、Windows WSL2 安装详解（CLI/本地部署） {#六windows-wsl2-安装详解clibendidebug}

如果你想在 Windows 上运行 CLI 交互版，WSL2（Windows Subsystem for Linux）是最稳定可靠的底层方案。

### 6.1 安装 WSL2

以管理员身份打开 Windows PowerShell，执行：

```powershell title="PowerShell 管理员"
wsl --install
```

这会自动安装 WSL2 和默认的 Ubuntu 发行版。安装完成后重启电脑，然后输入你想设置的 Ubuntu 用户名和密码。

**手动安装方式（备选）：**
```powershell title="PowerShell 管理员"
# 启用 WSL
wsl --install --no-distribution

# 查看可用的 Linux 发行版
wsl --list --online

# 安装 Ubuntu 22.04
wsl --install -d Ubuntu-22.04
```

验证安装：
```powershell title="PowerShell"
wsl --version
wsl --list --verbose
```

### 6.2 配置 WSL2 性能优化（内存限制）

WSL2 默认可能会吃满 Windows 内存，建议在 Windows 用户主目录（`C:\Users\你的用户名\`）创建 `.wslconfig` 文件：

```ini title="C:\Users\<用户名>\.wslconfig"
[wsl2]
# 限制 WSL2 最大使用内存（按需调整）
memory=8GB
# 分配 CPU 核心数
processors=4
# 交换空间
swap=4GB
# 关闭自动释放内存到 Windows（提高稳定性）
autoMemoryReclaim=gradual
```

保存后在 PowerShell 中重启 WSL：
```powershell title="PowerShell"
wsl --shutdown
```

### 6.3 WSL2 与 Windows 文件互通

在 Windows 文件资源管理器地址栏输入：
```text
\\wsl$\Ubuntu\home\你的用户名
```
即可直接图形化管理 WSL2 内部的 Hermes Agent 配置文件与数据。

## 七、CLI 快速安装（推荐） {#七cli-快速安装推荐}

### 7.1 Linux / macOS / WSL2 一键脚本

打开终端（WSL2、macOS 或 Linux），执行官方全自动安装脚本：

```bash title="Bash 终端"
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/install.sh | bash
```

该脚本会自动：
1. 检查 Python 3.10+ 环境（缺失会自动安装超高速包管理器 `uv`）；

4. 将 `hermes` 命令行命令注册到全局 PATH。

安装完成后，重载环境变量即可：
```bash title="Bash 终端"
source ~/.bashrc   # 或 source ~/.zshrc
hermes --version
```

### 7.2 Windows 原生 PowerShell（备选）

如果你不想安装 WSL2，也不使用桌面端，可使用社区提供的原生 PowerShell 脚本：

```powershell title="PowerShell"
irm https://res1.hermesagent.org.cn/install.ps1 | iex
```

## 九、Docker 安装部署（服务器/无痕隔离） {#九docker-安装部署服务器无痕隔离}

适合希望在云服务器上 7×24 小时无人值守运行，或者希望环境完全隔离的用户。

### 9.1 Docker 一键交互式运行

```bash title="Docker 运行"
docker run -it --rm \
  -v hermes_data:/root/.hermes \
  -e ANTHROPIC_API_KEY="your-api-key" \
  ghcr.io/nousresearch/hermes-agent:latest
```

### 9.2 Docker Compose 编排常驻

创建 `docker-compose.yml`：

```yaml title="docker-compose.yml"
services:
  hermes:
    image: ghcr.io/nousresearch/hermes-agent:latest
    container_name: hermes-agent
    restart: unless-stopped
    volumes:
      - ./data:/root/.hermes
    environment:
      - OPENROUTER_API_KEY=${OPENROUTER_API_KEY}
      - TELEGRAM_BOT_TOKEN=${TELEGRAM_BOT_TOKEN}
    stdin_open: true
    tty: true
```

启动服务：
```bash title="Docker 启动"
docker compose up -d
```

## 十、配置 LLM 模型提供商（CLI 模式） {#十配置-llm-模型提供商cli-模式}

CLI 模式支持通过命令交互式设置，也支持直接编辑配置文件。

### 10.1 交互式配置向导

```bash title="CLI 向导"
hermes model
```

终端会弹出交互式菜单，方向键上下选择：
1. **Anthropic**（推荐 Claude 3.7 / 3.5 Sonnet）
2. **OpenRouter**（性价比之王，聚合数百种模型）
3. **DeepSeek**（高性价比推理模型）
4. **Ollama / Local**（完全免费的本地模型）

### 10.2 手动编辑配置文件

配置文件位于 `~/.hermes/config.yaml`：

```yaml title="~/.hermes/config.yaml"
# 模型主配置
model:
  provider: "openrouter"
  name: "anthropic/claude-3.7-sonnet"
  api_key: "sk-or-v1-xxxxxxxxxxxx"
  temperature: 0.7

# 备用模型配置（可选，主模型故障时自动降级）
fallback_model:
  provider: "deepseek"
  name: "deepseek-chat"
  api_key: "sk-xxxxxxxxxxxx"

# 工具配置
tools:
  web_search: true
  terminal_sandbox: true
  file_ops: true
```

## 十一、常见问题排查（WSL 与网络专篇） {#十一常见问题排查wsl-与网络专篇}

### 1. WSL2 无法访问 Windows 宿主机代理
* **现象**：WSL2 内部 `curl google.com` 超时，无法连接外网 API。
* **解决办法**：在 WSL2 的 `~/.bashrc` 中配置自动获取宿主机 IP 代理：
  ```bash title="~/.bashrc"
  export host_ip=$(ip route | grep default | awk '{print $3}')
  export http_proxy="http://${host_ip}:7890"
  export https_proxy="http://${host_ip}:7890"
  ```
  注意需在 Windows 代理软件中开启「允许来自局域网的连接（Allow LAN）」。

### 2. WSL2 时间不同步导致 SSL 证书报错
* **现象**：`SSL: CERTIFICATE_VERIFY_FAILED`。
* **解决办法**：
  ```bash title="WSL 同步时间"
  sudo hwclock -s
  ```

### 3. CLI 启动提示找不到命令
* **现象**：`hermes: command not found`。
* **解决办法**：确保 `~/.local/bin` 在你的 PATH 中：
  ```bash title="~/.bashrc"
  echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
  source ~/.bashrc
  ```

| `hermes gateway` | 启动多端网关服务（连接 Telegram / 飞书） |
| `hermes doctor` | 一键诊断本地网络、依赖与配置健康度 |
| `hermes update` | 一键检查并更新到最新版本 |

### Windows 与 VS Code 终极协同技巧

在 Windows 安装 VS Code 并安装「WSL」扩展，在 WSL2 终端中直接输入：
```bash title="WSL2 终端"
code ~/.hermes
```
即可在 Windows 原生界面的 VS Code 中直接可视化编辑 Hermes 的记忆库文件、技能代码和配置日志！
