# 从零开始部署 Firefly（流萤）Astro 博客并上线 GitHub Pages

> [!TIP]
> **阅读建议**：
> 本文是《Firefly 博客搭建指南》实战第一篇。如果你还不熟悉项目的目录结构与配置文件分布，建议先阅读前置导读：[0. 新手先看：项目目录、配置文件和发布流程](/posts/0/)。

本教程面向纯小白，提供最简、可直接复制粘贴的落地流程，带你从零跑通本地预览与 GitHub Pages 全自动部署。

## 1. 项目地址与源码准备

* **GitHub 仓库**：https://github.com/coldairboys/firefly-replica
* **上游主题 Firefly**：https://github.com/CuteLeaf/Firefly

---

## 2. 环境准备（小白必看）

在开始之前，确保你的电脑已安装 **Git** 和 **Node.js**。

### 2.1 安装 Git

* **Windows 用户**：
  1. 访问官方下载：https://git-scm.com/download/win ；
  2. 下载安装包，一路保持默认点击 "Next" 完成安装；
  3. 安装完成后，打开 PowerShell 输入 `git --version`，输出版本号即表示安装成功。
* **macOS 用户**：
  打开终端，输入 `git --version`，若未安装系统会自动引导安装 Xcode Command Line Tools。

### 2.2 安装 Node.js 与 pnpm

本项目基于现代 Astro 5 构建，建议安装 **Node.js 20+ LTS** 版本：

1. 访问 Node 官网：https://nodejs.org/ 下载 LTS（长期支持版）；
2. 双击安装包完成安装，验证环境：
   ```bash
   node --version
   npm --version
   ```
3. 安装 pnpm（本项目强制统一使用 pnpm）：
   ```bash
   npm install -g pnpm
   pnpm --version
   ```

---

## 3. 本地快速克隆与运行

打开终端（Windows 推荐 PowerShell，macOS/Linux 推荐 Terminal），依次执行：

```bash title="终端命令行"
# 1. 克隆项目到本地
git clone https://github.com/coldairboys/firefly-replica.git
cd firefly-replica

# 2. 安装项目依赖（请使用 pnpm）
pnpm install

# 3. 启动本地开发预览
pnpm dev
```

终端输出成功后，在浏览器中打开：`http://localhost:4321`，即可看到博客页面！

---

## 4. 基本信息配置（换成你自己的信息）

用代码编辑器（如 VS Code）打开项目，找到主配置文件：`src/config/siteConfig.ts`。

### 4.1 站点基础信息

```typescript title="src/config/siteConfig.ts"
export const siteConfig: SiteConfig = {
    title: "你的博客名称",
    subtitle: "记录学习笔记与生活灵感",
    site_url: "https://你的域名或github.io",
    description: "这是我的个人博客，基于 Astro + Firefly 构建",
    keywords: ["博客", "前端", "笔记"],
    // ...
};
```

### 4.2 功能页面开关

```typescript title="src/config/siteConfig.ts"
pages: {
    friends: false,    // 是否开启友链页面
    sponsor: true,     // 是否开启赞助页面
    guestbook: true,   // 是否开启留言板
    gallery: false,    // 是否开启相册页面
},
```

按需将对应项修改为 `true`（开启）或 `false`（关闭）即可。

## 5. 如何写新文章

日常写文章的统一存放路径为：`src/content/posts/`。

新建任意 `.md` 文件（例如 `my-first-post.md`），在头部写好元数据：

```markdown title="src/content/posts/my-first-post.md"
---
title: 我的第一篇博客
published: 2026-10-15
description: 记录我搭建个人独立博客的第一天
category: 博客搭建
tags: [学习笔记, 博客搭建]
draft: false
---

这里开始书写正文内容，支持标准 Markdown 语法。
```

保存后，本地预览网页会立即实时刷新渲染新文章。

## 6. 部署上线到 GitHub Pages（全自动 CI/CD）

借助 GitHub Actions，你只需要把代码推送到 GitHub，云端就会全自动构建并发布。

> [!WARNING]
> **GitHub Pages 关键避坑提醒（重要）**：
> 如果你的 GitHub 仓库不是根域名（例如访问地址形如 `https://<你的用户名>.github.io/my-blog/`，带子路径），必须在根目录的 `astro.config.mjs` 中正确设置 `base` 路径：
> `base: '/my-blog/'`
> 否则上线后页面所有的 CSS、JS 和图片都会出现 **404 白屏**！若使用自定义独立域名（如 `https://blog.xxx.com`），则 `base` 保持 `/` 即可。

### 步骤 1：在 GitHub 创建新仓库
登录 GitHub，新建一个公开仓库（Repository），例如命名为 `my-firefly-blog`（无需勾选初始化 README）。

### 步骤 2：将代码推送到你的 GitHub 仓库
如果你是直接克隆本项目的本地目录，直接修改远程仓库地址即可：

```bash title="PowerShell / 终端"
# 1. 将远程地址替换为你自己的 GitHub 仓库
git remote set-url origin https://github.com/你的GitHub用户名/my-firefly-blog.git

# 2. 确认远程仓库已更新
git remote -v

# 3. 推送主分支代码
git branch -M main
git push -u origin main
```

### 步骤 3：配置 GitHub Actions 构建权限
进入你新建的 GitHub 仓库页面：
1. 点击顶部 **Settings** → 找到左侧 **Actions** → 点击 **General**；
2. 滑动到最下方的 **Workflow permissions**，选中 **Read and write permissions** 并点击 **Save**。

### 步骤 4：开启 GitHub Pages 服务
在仓库中继续点击 **Settings** → 左侧 **Pages**：
* 在 **Build and deployment** 下方的 **Source** 下拉菜单中，选择 **GitHub Actions**。

### 步骤 5：触发自动化部署
本项目内置了完善的自动化部署工作流文件（`.github/workflows/deploy.yml`）。你只需在本地执行：

```powershell title="发布脚本"
.publish-blog.bat
```

或者手动推送：

```bash title="Git 命令"
git add .
git commit -m "feat: site launch"
git push
```

打开 GitHub 仓库的 **Actions** 标签页，即可看到构建任务正在运行。大约 1~2 分钟完成后，访问你的专属博客网址即可！
