# 如何发布你的第一篇 Markdown 博客


> 手把手教你用这个静态博客，发布、编辑、预览 Markdown 文章

---

## 一、博客简介

这是一个支持 **Markdown** 语法、**默认深色模式**的纯静态博客系统。

### 核心特点

- 文章全部使用 `.md` 文件管理，无需数据库
- 默认启用深色模式，点击顶部按钮可切换浅色模式
- 状态自动保存，下次打开保持你的主题偏好
- 纯静态部署，可以发布到 GitHub Pages、Netlify 或任何静态托管服务

所有文章都存放在 `posts/` 文件夹中，添加新文章只需要创建一个新的 `.md` 文件即可。

---

## 二、目录结构说明

```
blog/
├── index.html           ← 博客首页
├── css/
│   └── style.css       ← 全局样式（支持深色/浅色）
├── js/
│   └── main.js         ← 核心逻辑（Markdown 渲染）
└── posts/              ← 文章仓库
    ├── guide.md        ← 教程文章（就是本文）
    └── your-post.md    ← 你的新文章
```

### 文件夹作用

- `posts/` — 你的文章仓库，所有 `.md` 文件都会被自动识别
- `css/` — 控制全站样式，包括深色/浅色主题
- `js/` — 核心脚本，负责解析 Markdown 和主题切换

---

## 三、发布新文章步骤

### ① 创建文章文件

在 `posts/` 文件夹中创建一个新的 `.md` 文件，文件名建议使用英文，例如：

```
posts/2026-05-13-my-first-post.md
```

### ② 编写文章元数据

在文件开头添加元数据，使用以下格式：

```markdown
# 文章标题
**发布日期:** 2026-05-13

> 文章摘要，简短描述这篇文章讲什么
```

> 注意：文章标题必须使用 `#` 开头，日期使用 `**发布日期:** YYYY-MM-DD` 格式，摘要使用 `>` 开头。

### ③ 用 Markdown 语法写正文

支持以下常用语法：

```markdown
## 二级标题

### 三级标题

这是普通段落。

**这是粗体**

这是 `行内代码`

- 列表项 1
- 列表项 2
- 列表项 3

1. 有序列表第一项
2. 有序列表第二项

> 引用块

[链接文字](https://example.com)
```

### ④ 代码块示例

要在文章中展示代码块语法，使用四个反引号包裹：

```markdown
```javascript
const greeting = "Hello World";
console.log(greeting);
```
```

渲染效果：

```javascript
const greeting = "Hello World";
console.log(greeting);
```

### ⑤ 保存并预览

1. 保存 `.md` 文件
2. 在浏览器中刷新博客首页
3. 新文章会自动出现在列表中

## 四、深色模式说明

### 默认深色模式

博客默认启用深色模式，界面配色如下：

- 背景：深灰色 `#1a1a1a`
- 文字：浅灰色 `#e0e0e0`
- 代码块：纯黑色背景 + 绿色文字 `#00ff00`

### 切换主题

点击页面顶部的 **☀** 或 **☾** 按钮可以切换：

- 深色模式：☾（月亮图标）
- 浅色模式：☀（太阳图标）

### 状态保存

主题选择会自动保存到浏览器本地存储，下次打开博客会保持你的偏好设置。

### 配色参数

可以在 `css/style.css` 中修改 CSS 变量自定义配色：

```css
[data-theme="dark"] {
    --bg-primary: #1a1a1a;      /* 主背景 */
    --bg-secondary: #242424;    /* 次级背景 */
    --bg-code: #0d0d0d;         /* 代码块背景 */
    --text-primary: #e0e0e0;     /* 主文字 */
    --code-text: #00ff00;        /* 代码文字 */
}

[data-theme="light"] {
    --bg-primary: #ffffff;      /* 浅色主背景 */
    --text-primary: #1a1a1a;    /* 浅色主文字 */
    --code-text: #22863a;        /* 浅色代码文字 */
}
```

## 五、手机端查看方式

### 方法一：本地传输

1. 将整个 `blog` 文件夹传到手机（微信、QQ、AirDrop 等）
2. 用手机浏览器打开 `index.html`

> 注意：由于浏览器安全限制，`.md` 文件可能无法直接加载。建议使用方法二。

### 方法二：本地服务器（推荐）

#### Windows / Mac / Linux 通用方法

1. 确保电脑安装了 Python
2. 打开终端，进入 blog 文件夹：

```bash
cd 你的博客路径/blog
```

3. 启动服务器：

```bash
# Windows
python -m http.server 8080

# Mac / Linux
python3 -m http.server 8080
```

4. 确保手机和电脑在同一 WiFi 网络下
5. 在手机浏览器中访问：`http://你的电脑IP:8080`

#### 查找电脑 IP 地址

**Windows:**

```bash
ipconfig
```

找到 `IPv4 地址`，类似 `192.168.x.x`

**Mac:**

```bash
ifconfig | grep inet
```

找到 `inet` 后面的地址

### 方法三：部署到 GitHub Pages

1. 在 GitHub 创建新仓库
2. 上传所有博客文件
3. 进入 Settings → Pages
4. Source 选择 `main` 分支
5. 等待部署完成，访问 `https://你的用户名.github.io/仓库名`

## 六、进阶技巧

### 修改博客名称

打开 `index.html`，修改以下位置：

```html
<h1>你的博客名</h1>
<p class="intro">你的博客简介...</p>
```

### 添加更多文章

在 `js/main.js` 中找到 `articles` 数组，添加新文章：

```javascript
const articles = [
    { title: '第一篇', date: '2026-05-12', summary: '摘要', file: 'posts/guide.md' },
    { title: '第二篇', date: '2026-05-13', summary: '摘要', file: 'posts/your-post.md' }
];
```

### 自定义代码高亮

在 `css/style.css` 中修改代码块样式：

```css
.post-content pre {
    background: #你的背景色;
    border: 1px solid #边框色;
}

.post-content pre code {
    color: #你的代码颜色;
}
```

### 添加分类标签

可以在文章元数据中添加分类：

```markdown
# 文章标题
**发布日期:** 2026-05-12
**分类:** 教程

> 摘要...
```

## 七、Markdown 语法速查

| 语法 | 效果 |
|------|------|
| `# 标题` | 一级标题 |
| `## 标题` | 二级标题 |
| `**粗体**` | **粗体** |
| `` `代码` `` | `行内代码` |
| ``` | 代码块 |
| `- 列表` | - 无序列表 |
| `1. 列表` | 1. 有序列表 |
| `> 引用` | > 引用块 |
| `[文字](链接)` | [链接文字](https://example.com) |

## 八、常见问题

### Q: 为什么文章加载失败？

A: 确保通过本地服务器访问（`http://localhost:xxxx`），而不是直接打开 HTML 文件。浏览器安全策略会阻止直接加载本地 Markdown 文件。

### Q: 如何修改深色模式的配色？

A: 编辑 `css/style.css` 中的 CSS 变量。

### Q: 支持哪些 Markdown 语法？

A: 支持标题、段落、粗体、斜体、代码块、列表、引用、链接。暂不支持表格和图片（可使用 HTML）。
